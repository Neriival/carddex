# CardDex – Sua coleção de cartas

Site para fãs de Pokémon TCG marcarem as cartas que já têm, organizado por **séries → coleções → cartas**, tudo em português.

- Clique na carta para abri-la em tamanho grande, com efeito 3D e informações
- Marcações salvas no navegador (localStorage)
- Dados e imagens da [TCGdex](https://tcgdex.dev)

## Rodar localmente
Use o Live Server do VS Code no `index.html`.

## Deixar as imagens dentro do projeto
```bash
python scripts/baixar_cartas.py
```
Veja o `LEIA-ME.txt` para a estrutura de pastas e como adicionar coleções.

## GitHub Pages
Settings → Pages → branch `main` → pasta `/ (root)`.
