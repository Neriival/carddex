CARDDEX – Sua coleção de cartas
================================
Site: https://neriival.github.io/carddex/

COMO USAR
1) Abra a pasta no VS Code e rode com "Live Server" (clique direito no index.html).
2) O site já funciona sozinho: busca as cartas pela internet.
3) Para ter TUDO dentro do projeto (mais rápido e offline), rode no terminal:
      python scripts/baixar_cartas.py            (tudo)
      python scripts/baixar_cartas.py me         (só a série Mega Evolução)
      python scripts/baixar_cartas.py me04       (só uma coleção)
   Depois suba a pasta inteira para o GitHub.

ADICIONAR UMA COLEÇÃO
Em dados/series.json, dentro da série, inclua:
  { "id": "me06", "nome": "Nome em português", "busca": "Nome em inglês", "lancamento": "AAAA-MM-DD", "total": 100 }
Para ver os nomes/ids que a TCGdex usa:  python scripts/baixar_cartas.py --listar me
O script atualiza o "total" sozinho depois de baixar.
COLEÇÃO QUE AINDA NÃO SAIU: coloque com "total": 0 e "emBreve": true, por exemplo
  { "id": "me06", "nome": "Delta Reign", "busca": "Delta Reign", "lancamento": "2026-11-06", "total": 0, "emBreve": true }
O site mostra "Em breve" com a data. Todo dia o robô (precos.yml) roda  python scripts/baixar_cartas.py --em-breve:
quando a TCGdex publicar as cartas, ele baixa tudo, tira o "emBreve" e a coleção aparece sozinha no site.
Depois, se quiser preço da Liga, coloque a sigla da coleção em SIGLAS no atualizar_precos_liga.py.

ADICIONAR UMA SÉRIE
Crie outro bloco em "series" com o mesmo id usado na TCGdex (ex.: "swsh"), "jogo": "pokemon" e suas coleções.
Com "imagens": "mini" o script guarda só a miniatura no projeto e a carta grande vem da internet.
Isso mantém o projeto abaixo de 1 GB, o limite do GitHub Pages (Escarlate e Violeta, Espada e Escudo
e Sol e Lua usam esse modo; Mega Evolução guarda tudo).

JOGOS (Pokémon, Yu-Gi-Oh!, Dragon Ball...)
A lista fica em "jogos" no dados/series.json. Um jogo sem séries aparece como "Em breve".
Para um jogo novo: inclua { "id": "...", "nome": "..." } em "jogos" e o ícone em assets/img/jogos/<id>.svg.
As cartas de Yu-Gi-Oh! e Dragon Ball ainda não têm de onde vir: a TCGdex só tem Pokémon.

LOGOS DAS COLEÇÕES
O script baixa o logo oficial quando existe (assets/img/colecoes/<serie>/<colecao>.webp).
Quando não existe, o site usa o .svg da mesma pasta (nome da coleção no estilo CardDex).
Para usar um logo seu, coloque <colecao>.webp na pasta: ele tem prioridade sobre o .svg.

CONTAS, RANKING, PERFIS, PAINEL ADM E PARCEIROS (Supabase – projeto "carddex", já configurado)
- Conta com nick, sexo e personagem (menino, menina ou treinador do anime) ou foto, e banner do perfil
  (um por tipo de Pokémon ou imagem própria); as cartas marcadas e as repetidas ficam salvas na conta.
- Nível do colecionador pelo total de cartas, mostrado no anel dourado em volta do personagem.
- Ranking por total de cartas; clicando em alguém abre o perfil público (com a vitrine de 5 cartas).
- Amigos: pedido pelo nick (Meu perfil) ou pelo botão no perfil público; o outro aceita ou recusa.
  Quem pode ver a coleção completa: Todo mundo, Só amigos ou Ninguém (Meu perfil).
- O link "Admin" do menu aparece para quem estiver na tabela "admins": contas, números do site,
  8 quadrados de parceiros (com cliques) e moderação de fotos e banners.
- Banco e regras de segurança: docs/supabase.sql. Passo a passo e limites do plano grátis: docs/SUPABASE.md.
Sem o Supabase configurado o site funciona só no navegador e os quadrados mostram "Seja um parceiro".

PREÇOS (em reais)
Referência principal: Liga Pokémon (ligapokemon.com.br), o mercado brasileiro. O site mostra o preço MÉDIO
(e o menor e o maior na carta grande).
- scripts/atualizar_precos_liga.py abre a página de cada coleção na Liga (um acesso traz todas as cartas).
  A Liga pede 6 minutos entre acessos, então todas as coleções levam horas, sempre começando pelas
  coleções há mais tempo sem atualizar.
  ATENÇÃO: no GitHub a Liga bloqueia o acesso, então o agendamento automático foi DESLIGADO (23/10/2026).
  Rode no computador de casa (depois rode "git pull", e então commit e push dos arquivos de dados/precos-liga):
      python scripts/atualizar_precos_liga.py              (tudo; deixe rodando)
      python scripts/atualizar_precos_liga.py me01 sv01    (só algumas coleções)
  O script termina com ERRO quando não consegue atualizar nenhuma coleção.
- Coleção nova: além do baixar_cartas.py, coloque a sigla dela na Liga em SIGLAS, no começo do
  atualizar_precos_liga.py (a sigla aparece em ligapokemon.com.br/?view=cards/edicoes).
Reserva: Cardmarket (loja europeia), em euro convertido para real. Só é usado nas coleções que ainda não têm
preço da Liga. Todo dia às 6h o GitHub roda scripts/atualizar_precos.py (e, no mesmo robô, faz uma
leitura pequena no Supabase para o banco não ser pausado por falta de uso).
ATENÇÃO: como o robô salva os preços todo dia, rode "git pull" antes de publicar mudanças suas.

BACKUP
Em "Minhas cartas" dá para exportar um arquivo .json (marcações e repetidas) e importar em outro aparelho.
A importação junta com o que já está marcado, não apaga nada.

ATUALIZAR O SITE SEM CACHE
No index.html, cada .css e .js termina com ?v=AAAAMMDD. Ao publicar mudanças, troque essa versão
(em todas as linhas) para os navegadores e o app instalado baixarem os arquivos novos na hora.

PADRÃO DE CÓDIGO (para tudo ficar organizado igual)
- Depois de mexer em CSS ou JS, rode:   python scripts/formatar_codigo.py
  (uma vez antes: pip install jsbeautifier cssbeautifier esprima). Ele só arruma espaços e quebras de linha.
  Para só conferir, sem mudar nada:     python scripts/formatar_codigo.py --conferir
- CSS: uma propriedade por linha (terminando com ;), linha em branco entre as regras, títulos de seção
  /* ===== NOME ===== */ e os ajustes de celular num @media(max-width:760px) no fim do próprio arquivo.
- JS: cada arquivo começa com um cabeçalho dizendo o que faz; cada função tem um comentário de uma linha.
- Tela nova: js/telas/<tela>.js + css/telas/<tela>.css, incluídos no index.html na seção certa.
- Função usada em vários lugares vai para js/base/util.js (no Python, scripts/comum.py): nada de copiar e colar.
