CARDDEX – Sua coleção de cartas
================================
Site: https://neriival.github.io/carddex/

COMO USAR
1) Abra a pasta no VS Code e rode com "Live Server" (clique direito no index.html).
2) O site já funciona sozinho: busca as cartas pela internet.
3) Para ter TUDO dentro do projeto (mais rápido e offline), rode no terminal:
      python scripts/baixar_cartas.py            (tudo)
      python scripts/baixar_cartas.py me         (só a série Mega Evolução)
      python scripts/baixar_cartas.py me04       (só uma coleção)
   Depois suba a pasta inteira para o GitHub.

ADICIONAR UMA COLEÇÃO
Em dados/series.json, dentro da série, inclua:
  { "id": "me06", "nome": "Nome em português", "busca": "Nome em inglês", "lancamento": "AAAA-MM-DD", "total": 100 }
Para ver os nomes/ids que a TCGdex usa:  python scripts/baixar_cartas.py --listar me
O script atualiza o "total" sozinho depois de baixar.

ADICIONAR UMA SÉRIE
Crie outro bloco em "series" com o mesmo id usado na TCGdex (ex.: "swsh"), "jogo": "pokemon" e suas coleções.
Com "imagens": "mini" o script guarda só a miniatura no projeto e a carta grande vem da internet.
Isso mantém o projeto abaixo de 1 GB, o limite do GitHub Pages (Escarlate e Violeta, Espada e Escudo
e Sol e Lua usam esse modo; Mega Evolução guarda tudo).

JOGOS (Pokémon, Yu-Gi-Oh!, Dragon Ball...)
A lista fica em "jogos" no dados/series.json. Um jogo sem séries aparece como "Em breve".
Para um jogo novo: inclua { "id": "...", "nome": "..." } em "jogos" e o ícone em assets/img/jogos/<id>.svg.
As cartas de Yu-Gi-Oh! e Dragon Ball ainda não têm de onde vir: a TCGdex só tem Pokémon.

LOGOS DAS COLEÇÕES
O script baixa o logo oficial quando existe (assets/img/colecoes/<serie>/<colecao>.webp).
Quando não existe, o site usa o .svg da mesma pasta (nome da coleção no estilo CardDex).
Para usar um logo seu, coloque <colecao>.webp na pasta: ele tem prioridade sobre o .svg.

CONTAS, RANKING, PERFIS, PAINEL ADM E PARCEIROS (Supabase – projeto "carddex", já configurado)
- Conta com nick, sexo e personagem ou foto; as cartas marcadas e as repetidas ficam salvas na conta.
- Ranking por total de cartas; clicando em alguém abre o perfil público (com a vitrine de 5 cartas).
- O link "Admin" do menu aparece para quem estiver na tabela "admins": contas, números do site,
  8 quadrados de parceiros (com cliques) e moderação de fotos.
- Banco e regras de segurança: docs/supabase.sql. Passo a passo e limites do plano grátis: docs/SUPABASE.md.
Sem o Supabase configurado o site funciona só no navegador e os quadrados mostram "Seja um parceiro".

BACKUP
Em "Minhas cartas" dá para exportar um arquivo .json (marcações e repetidas) e importar em outro aparelho.
A importação junta com o que já está marcado, não apaga nada.

ATUALIZAR O SITE SEM CACHE
No index.html, cada .css e .js termina com ?v=AAAAMMDD. Ao publicar mudanças, troque essa versão
(em todas as linhas) para os navegadores e o app instalado baixarem os arquivos novos na hora.
